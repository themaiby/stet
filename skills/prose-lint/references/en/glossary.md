# English: judgement notes

Not a word list. `ai-tells`, `write-good` and the generated `ProseEN.Plain`
already carry those, and each finding arrives with its own suggestion. This file
covers the calls those rules cannot make.

## When the long word is right

`terminate` beats `end` in a contract. `facilitate` beats `help` when a third
party runs the session without joining it. Register is part of meaning, and a
swap that flattens it costs more than it saves.

## When the padding does work

`It is worth noting that` can nearly always go. Before a real caveat the reader would
otherwise skip, keep it. Read what follows the phrase before cutting it.

## Adjectives

`vibrant`, `pivotal`, `seamless`, `groundbreaking`, `transformative`. Ask what
fact the adjective stands in for, and write that instead. If no fact turns up,
the adjective was the whole sentence and it goes.

## Passive voice

Documentation describes what happens to a thing, so the thing is often the right
subject. `write-good.Passive` comes demoted for that reason. Change it only when
naming the actor tells the reader something.
