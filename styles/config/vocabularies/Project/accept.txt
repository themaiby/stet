# One regular expression per line, so a single line covers every inflected form:
#
#   сорсинг.*      clears сорсинг, сорсингу, сорсингом
#   [Ff]eedback    clears both cases
#
# Entries here reach every rule that matches whole words, in every language.
# They do NOT reach a rule declaring `nonword: true`, which matches below the
# word level: that is most punctuation rules and 36 of the 76 in ai-tells.
# Ask `stet rule <Style>.<Name>` before adding a line, and silence the rest in
# .vale.ini instead.
#
# An empty file means no exceptions.
